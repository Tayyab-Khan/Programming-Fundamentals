## 🚀 Complex Computing Problem (CCP)

**Project:** C-Language Currency Converter  
**Team:** ZenCoders

The CCP served as the capstone project for the semester. We built a fully functional Currency Converter entirely in **C**. 

Inside the `/CCP` directory, the project is organized into:
* **Project Code:** The core C application source files.
* **Documentation:** The initial project proposal and the comprehensive final report.
* **Media:** Presentation slides and project demonstration video links.
